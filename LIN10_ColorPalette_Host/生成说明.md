# LIN10 颜色上位机

- Qt 工程：`LIN10_ColorPalette_Host.pro`
- 控制帧：`HU_ALMCtrl`
- RGB 输入：`RGB_R / RGB_G / RGB_B`，保持表中原始 8 位数值
- 默认目标：`CtrlList = 0x07FF`，即 ALM1～ALM11
- 默认亮度：`Brightness = 200`（LDF 物理值为 100%）
- 颜色数量：256；每页 30 个，共 9 页

颜色名称由 CIE `x/y` 转换得到色相区间，并加三位编号保证唯一。
按钮背景直接使用对应 RGB，悬停提示显示 `x/y` 和 RGB 十六进制值。

重新生成配置时运行：

```bat
regenerate_profile.cmd
```

公司 SafeNet 会加密新复制的 `.cpp/.py`。因此本工程用等价的标准
`.cc` 扩展名参与 Qt 编译，生成器以 `.py.txt` 保存并由 Python 直接执行。
