# RGBW 最大显色与温度修正详细数学建模版

## 0. 整体思想

本文建立一个从目标颜色到 RGBW 四通道归一化驱动向量的数学模型。整体思想分为三个层次。

第一层是单色最大 Ra 求解。对一个给定目标颜色 T，将 RGBW 分解参数化为白光比例 ρ。ρ 决定 White 亮度、RGB 子目标、RGB 权重和混合光谱。因此，单色问题可以写成在可行集合 Ω<sub>T</sub> 上最大化 R<sub>a</sub>(ρ) 的一维约束优化问题。

<p align="center"><font face="Times New Roman">T → Ω<sub>T</sub> → S<sub>mix</sub>(λ;ρ) → R<sub>a</sub>(ρ) → ρ<sup>*</sup>(T)</font></p>

第二层是全色域最大 Ra 建模。在 RGB 色域内构造三角网格，对每个网格点 P<sub>ijk</sub> 求解单色最大 Ra，得到 W<sub>0,ijk</sub>。全部 W<sub>0,ijk</sub> 形成基础最优比例场。该层成立的核心前提是：最大显色白光比例 ρ<sup>*</sup>(T) 关于目标颜色 T 是局部连续的。因此，在足够小的邻域内，离散最优比例场可以用低阶局部模型近似。对于任意非网格目标，通过欧式范数加权局部回归得到连续估计 W<sub>25</sub>。

<p align="center"><font face="Times New Roman">ρ<sup>*</sup>: 𝒢 → [0,1], &nbsp; ρ<sup>*</sup> ∈ C<sup>0</sup>(𝒢)</font></p>

<p align="center"><font face="Times New Roman">P<sub>ijk</sub> → W<sub>0,ijk</sub> → 𝓦<sub>0</sub> → W<sub>25</sub></font></p>

第三层是考虑温度后的最大 Ra 近似。温度变化引起光谱、色坐标和亮度关系变化，因此基础比例 W<sub>25</sub> 需要修正。该层成立的核心前提是：最优白光比例的温度变化量 Δρ 具有连续性，即 Δρ 可以由目标色坐标、基础比例和温度的连续函数近似；文中记为 ΔW。模型使用目标色坐标、基础比例和温度变量构造分段二阶曲面，估计比例偏移 ΔW，得到 W<sub>formula</sub>。再通过色域最大可行比例 W<sub>max</sub> 约束，得到最终可实现比例 W<sub>final</sub>。

<p align="center"><font face="Times New Roman">Δρ: 𝒢 × [0,1] × Θ → ℝ, &nbsp; Δρ ∈ C<sup>0</sup>(𝒢 × [0,1] × Θ)</font></p>

<p align="center"><font face="Times New Roman">W<sub>25</sub> → ΔW(x,y,W<sub>25</sub>,θ) → W<sub>formula</sub> → W<sub>final</sub> → d<sub>RGBW</sub></font></p>

## 2. 光谱色度模型

对任意通道 c ∈ 𝒞，光谱到 XYZ 的积分关系为：

<p align="center"><font face="Times New Roman">X<sub>c</sub> = Σ S<sub>c</sub>(λ)x̄(λ)Δλ</font></p>

<p align="center"><font face="Times New Roman">Y<sub>c</sub> = Σ S<sub>c</sub>(λ)ȳ(λ)Δλ</font></p>

<p align="center"><font face="Times New Roman">Z<sub>c</sub> = Σ S<sub>c</sub>(λ)z̄(λ)Δλ</font></p>

对应色坐标为：

<p align="center"><font face="Times New Roman">x<sub>c</sub> = X<sub>c</sub> / (X<sub>c</sub> + Y<sub>c</sub> + Z<sub>c</sub>)</font></p>

<p align="center"><font face="Times New Roman">y<sub>c</sub> = Y<sub>c</sub> / (X<sub>c</sub> + Y<sub>c</sub> + Z<sub>c</sub>)</font></p>

已知色度点 P = (x,y) 和亮度 Y 时：

<p align="center"><font face="Times New Roman">XYZ(P,Y) = [xY/y, Y, (1 − x − y)Y/y]<sup>T</sup></font></p>

该部分说明：颜色匹配由 XYZ 线性空间约束，显色指数由完整光谱 S(λ) 决定。因此，RGBW 分解需要同时处理色度可行性和光谱质量最优性。

## 3. 白光比例参数化

定义目标颜色：

<p align="center"><font face="Times New Roman">T = (x<sub>T</sub>, y<sub>T</sub>, Y<sub>T</sub>)</font></p>

白光亮度比例为：

<p align="center"><font face="Times New Roman">ρ = Y<sub>W,out</sub> / Y<sub>T</sub>, 0 ≤ ρ ≤ 1</font></p>

于是：

<p align="center"><font face="Times New Roman">Y<sub>W,out</sub> = ρY<sub>T</sub></font></p>

<p align="center"><font face="Times New Roman">Y<sub>RGB,out</sub> = (1 − ρ)Y<sub>T</sub></font></p>

ρ 是白光通道与 RGB 子系统之间分配亮度的自由变量。不同 ρ 可以保持相近色度，却形成不同混合光谱，因此 R<sub>a</sub> 通常随 ρ 改变。

## 4. RGB 子目标与可行域

设 P<sub>W</sub> = (x<sub>W</sub>,y<sub>W</sub>)，定义：

<p align="center"><font face="Times New Roman">γ(ρ) = ρy<sub>T</sub> / y<sub>W</sub></font></p>

扣除 White 分量后，RGB 子目标为：

<p align="center"><font face="Times New Roman">P<sub>RGB</sub>(ρ) = P<sub>W</sub> + [P<sub>T</sub> − P<sub>W</sub>] / [1 − γ(ρ)]</font></p>

RGB 色域凸包为：

<p align="center"><font face="Times New Roman">𝒢 = Conv(P<sub>R</sub>,P<sub>G</sub>,P<sub>B</sub>)</font></p>

色域可行性约束：

<p align="center"><font face="Times New Roman">P<sub>RGB</sub>(ρ) ∈ 𝒢</font></p>

构造：

<p align="center"><font face="Times New Roman">A<sub>RGB</sub> = [V<sub>R</sub> V<sub>G</sub> V<sub>B</sub>]</font></p>

RGB 权重为：

<p align="center"><font face="Times New Roman">w<sub>RGB</sub>(ρ) = A<sub>RGB</sub><sup>−1</sup>XYZ(P<sub>RGB</sub>(ρ),Y<sub>RGB,out</sub>)</font></p>

物理可实现性约束：

<p align="center"><font face="Times New Roman">w<sub>R</sub>(ρ) ≥ 0, w<sub>G</sub>(ρ) ≥ 0, w<sub>B</sub>(ρ) ≥ 0</font></p>

因此，目标 T 的可行白光比例集合为：

<p align="center"><font face="Times New Roman">Ω<sub>T</sub> = {ρ | 0 ≤ ρ ≤ 1, P<sub>RGB</sub>(ρ) ∈ 𝒢, w<sub>RGB</sub>(ρ) ≥ 0}</font></p>

## 5. 最大显色优化

对于任意 ρ ∈ Ω<sub>T</sub>，混合光谱为：

<p align="center"><font face="Times New Roman">S<sub>mix</sub>(λ;ρ) = ρS<sub>W</sub>(λ) + w<sub>R</sub>(ρ)S<sub>R</sub>(λ) + w<sub>G</sub>(ρ)S<sub>G</sub>(λ) + w<sub>B</sub>(ρ)S<sub>B</sub>(λ)</font></p>

显色指数目标函数：

<p align="center"><font face="Times New Roman">R<sub>a</sub>(ρ) = CRI[S<sub>mix</sub>(λ;ρ)]</font></p>

最大显色比例定义为：

<p align="center"><font face="Times New Roman">ρ<sup>*</sup>(T) = arg max<sub>ρ∈Ω<sub>T</sub></sub> R<sub>a</sub>(ρ)</font></p>

基础最优比例函数：

<p align="center"><font face="Times New Roman">W<sub>0</sub>(T) = ρ<sup>*</sup>(T)</font></p>

这里 arg max 的结果是白光比例，而不是 R<sub>a</sub> 的数值。

## 6. 离散比例场

在 RGB 色域中构造三角网格：

<p align="center"><font face="Times New Roman">P<sub>ijk</sub> = [iP<sub>R</sub> + jP<sub>G</sub> + kP<sub>B</sub>] / N,  i+j+k=N</font></p>

每个网格点的基础最优比例为：

<p align="center"><font face="Times New Roman">W<sub>0,ijk</sub> = W<sub>0</sub>(P<sub>ijk</sub>)</font></p>

全部样本构成离散比例场：

<p align="center"><font face="Times New Roman">𝓦<sub>0</sub> = {(P<sub>ijk</sub>, W<sub>0,ijk</sub>)}</font></p>

## 7. 欧式范数加权局部估计

给定目标点 Z<sub>0</sub> = (u′<sub>0</sub>,v′<sub>0</sub>)，在邻域样本 𝒩 = {(u′<sub>n</sub>,v′<sub>n</sub>,W<sub>n</sub>)} 上建立局部仿射模型：

<p align="center"><font face="Times New Roman">W(u′,v′) = a(u′ − u′<sub>0</sub>) + b(v′ − v′<sub>0</sub>) + c</font></p>

其中 a、b 为局部一阶变化率，c 为目标点处的函数值。

欧式范数距离：

<p align="center"><font face="Times New Roman">d<sub>n</sub> = ‖Z<sub>n</sub> − Z<sub>0</sub>‖<sub>2</sub></font></p>

归一化权重：

<p align="center"><font face="Times New Roman">ω<sub>n</sub> = [1 / (d<sub>n</sub><sup>2</sup> + ε)] / Σ<sub>m∈𝒩</sub>[1 / (d<sub>m</sub><sup>2</sup> + ε)]</font></p>

加权最小二乘：

<p align="center"><font face="Times New Roman">min<sub>a,b,c</sub> Σ<sub>n∈𝒩</sub>ω<sub>n</sub>[aΔu′<sub>n</sub> + bΔv′<sub>n</sub> + c − W<sub>n</sub>]<sup>2</sup></font></p>

由于目标点处 Δu′ = 0 且 Δv′ = 0：

<p align="center"><font face="Times New Roman">W(u′<sub>0</sub>,v′<sub>0</sub>) = c</font></p>

基础比例估计为：

<p align="center"><font face="Times New Roman">W<sub>25</sub> = c</font></p>

## 8. 十项温度基函数

令：

<p align="center"><font face="Times New Roman">W = clamp(W<sub>25</sub>,0,1)</font></p>

十项基函数定义如下：

| 序号 | 基函数 | 数学意义 |
|---:|---|---|
| 0 | φ<sub>0</sub> = 1 | 常数偏置项，描述全局平均温度偏移 |
| 1 | φ<sub>1</sub> = x | 目标色度 x 方向的一阶影响 |
| 2 | φ<sub>2</sub> = y | 目标色度 y 方向的一阶影响 |
| 3 | φ<sub>3</sub> = W | 基础白光比例的一阶影响 |
| 4 | φ<sub>4</sub> = xy | x 与 y 的色度耦合影响 |
| 5 | φ<sub>5</sub> = xW | x 与基础比例的耦合影响 |
| 6 | φ<sub>6</sub> = yW | y 与基础比例的耦合影响 |
| 7 | φ<sub>7</sub> = W<sup>2</sup> | 白光比例方向的二阶非线性 |
| 8 | φ<sub>8</sub> = x<sup>2</sup> | x 方向的二阶曲率 |
| 9 | φ<sub>9</sub> = y<sup>2</sup> | y 方向的二阶曲率 |

记：

<p align="center"><font face="Times New Roman">φ(x,y,W) = [φ<sub>0</sub>,φ<sub>1</sub>,...,φ<sub>9</sub>]<sup>T</sup></font></p>

## 9. 温度扰动曲面

温度归一化：

<p align="center"><font face="Times New Roman">t = [clamp(θ,θ<sub>0</sub>,θ<sub>max</sub>) − θ<sub>0</sub>] / [θ<sub>max</sub> − θ<sub>0</sub>]</font></p>

按 W 的区间选择分段 s。每段具有两组系数 α<sub>s</sub> 与 β<sub>s</sub>：

<p align="center"><font face="Times New Roman">F<sub>1,s</sub>(x,y,W) = α<sub>s</sub><sup>T</sup>φ(x,y,W)</font></p>

<p align="center"><font face="Times New Roman">F<sub>2,s</sub>(x,y,W) = β<sub>s</sub><sup>T</sup>φ(x,y,W)</font></p>

温度偏移：

<p align="center"><font face="Times New Roman">ΔW = tF<sub>1,s</sub>(x,y,W) + t<sup>2</sup>F<sub>2,s</sub>(x,y,W)</font></p>

曲面输出：

<p align="center"><font face="Times New Roman">W<sub>formula</sub> = clamp(W + ΔW,0,1)</font></p>

## 10. 可行域边界与最终分解

设 W<sub>max</sub> 为目标 T 在当前 RGB 凸包内允许的最大白光比例。最终比例：

<p align="center"><font face="Times New Roman">W<sub>final</sub> = min(W<sub>formula</sub>,W<sub>max</sub>)</font></p>

令 ρ = W<sub>final</sub>，最终驱动向量为：

<p align="center"><font face="Times New Roman">d<sub>RGBW</sub> = [w<sub>R</sub>,w<sub>G</sub>,w<sub>B</sub>,ρ]<sup>T</sup></font></p>

## 模型闭环

<p align="center"><font face="Times New Roman">d<sub>RGBW</sub> = f<sub>mix</sub>(T, min[f<sub>thermal</sub>(x,y,f<sub>local</sub>(u′,v′),θ), W<sub>max</sub>])</font></p>
