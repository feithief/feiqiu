# RGBW 最大显色指数模型精简版

## 一句话解释

在所有能混出目标颜色的 RGBW 比例中，先确定显色指数最高的白光比例，再用局部估计和温度曲面把该比例推广到任意目标颜色与任意温度。

## 整体思路

整体建模分为三个层次。

第一，求解单个目标颜色的最大 Ra。  
给定一个目标颜色 T，把 RGBW 分解写成关于白光比例 ρ 的一维问题。对每一个可行 ρ，先求出 RGB 子目标和 RGB 权重，再生成混合光谱 S<sub>mix</sub>(λ;ρ)，计算 R<sub>a</sub>(ρ)。在全部可行比例 Ω<sub>T</sub> 中，取使 R<sub>a</sub> 最大的比例 ρ<sup>*</sup>(T)。这是单色最大显色问题。

<p align="center"><font face="Times New Roman">T → Ω<sub>T</sub> → S<sub>mix</sub>(λ;ρ) → R<sub>a</sub>(ρ) → ρ<sup>*</sup>(T)</font></p>

第二，求解全色域最大 Ra。  
在 RGB 色域内构造三角网格，对每个网格目标 P<sub>ijk</sub> 重复单色最大 Ra 求解，得到离散最优比例 W<sub>0,ijk</sub>。这些点组成基础最优比例场 𝓦<sub>0</sub>。这一层的数学前提是：最大显色白光比例可以看作目标颜色位置的连续函数；因此相邻颜色点的最优比例应当平滑变化。基于该连续性假设，对于任意非网格目标，再用欧式范数加权的局部仿射回归估计其基础比例 W<sub>25</sub>。这是从“单点最优”到“全色域连续比例场”的推广。

<p align="center"><font face="Times New Roman">ρ<sup>*</sup>: 𝒢 → [0,1], &nbsp; ρ<sup>*</sup> ∈ C<sup>0</sup>(𝒢)</font></p>

<p align="center"><font face="Times New Roman">P<sub>ijk</sub> → ρ<sup>*</sup>(P<sub>ijk</sub>) → 𝓦<sub>0</sub> → W<sub>25</sub></font></p>

第三，求解考虑温度后的最大 Ra 近似。  
温度变化会改变通道光谱、色坐标和相对亮度，使基础比例 W<sub>25</sub> 不再严格最优。这一层的数学前提是：温度引起的最优比例变化量 Δρ 是关于目标色坐标、基础比例和温度的连续函数；文中用 ΔW 表示该比例偏移。因此引入温度变量 θ，用分段二阶曲面估计 ΔW，得到 W<sub>formula</sub>。最后再用色域边界 W<sub>max</sub> 限制该比例，得到最终可实现比例 W<sub>final</sub>，并完成 RGBW 分解。

<p align="center"><font face="Times New Roman">Δρ: 𝒢 × [0,1] × Θ → ℝ, &nbsp; Δρ ∈ C<sup>0</sup>(𝒢 × [0,1] × Θ)</font></p>

<p align="center"><font face="Times New Roman">W<sub>25</sub> → ΔW(x,y,W<sub>25</sub>,θ) → W<sub>formula</sub> → W<sub>final</sub> → d<sub>RGBW</sub></font></p>

## 1. 输入与目标

目标颜色：

<p align="center"><font face="Times New Roman">T = (x<sub>T</sub>, y<sub>T</sub>, Y<sub>T</sub>)</font></p>

四个基光谱：

<p align="center"><font face="Times New Roman">S<sub>R</sub>(λ), S<sub>G</sub>(λ), S<sub>B</sub>(λ), S<sub>W</sub>(λ)</font></p>

目标是在颜色可实现约束下，最大化混合光谱显色指数 R<sub>a</sub>。

## 2. 白光比例

定义白光比例：

<p align="center"><font face="Times New Roman">ρ = Y<sub>W,out</sub> / Y<sub>T</sub></font></p>

则：

<p align="center"><font face="Times New Roman">Y<sub>W,out</sub> = ρY<sub>T</sub></font></p>

<p align="center"><font face="Times New Roman">Y<sub>RGB,out</sub> = (1 − ρ)Y<sub>T</sub></font></p>

ρ 是决定光谱显色质量的核心变量。

## 3. RGB 子目标

设 P<sub>T</sub> = (x<sub>T</sub>, y<sub>T</sub>)，P<sub>W</sub> = (x<sub>W</sub>, y<sub>W</sub>)。

<p align="center"><font face="Times New Roman">γ = ρy<sub>T</sub> / y<sub>W</sub></font></p>

<p align="center"><font face="Times New Roman">P<sub>RGB</sub>(ρ) = P<sub>W</sub> + [P<sub>T</sub> − P<sub>W</sub>] / [1 − γ]</font></p>

可行性条件：

<p align="center"><font face="Times New Roman">P<sub>RGB</sub>(ρ) ∈ Conv(P<sub>R</sub>,P<sub>G</sub>,P<sub>B</sub>)</font></p>

## 4. RGB 权重

<p align="center"><font face="Times New Roman">A<sub>RGB</sub> = [V<sub>R</sub> V<sub>G</sub> V<sub>B</sub>]</font></p>

<p align="center"><font face="Times New Roman">w<sub>RGB</sub>(ρ) = A<sub>RGB</sub><sup>−1</sup>XYZ(P<sub>RGB</sub>(ρ),Y<sub>RGB,out</sub>)</font></p>

约束：

<p align="center"><font face="Times New Roman">w<sub>R</sub> ≥ 0, w<sub>G</sub> ≥ 0, w<sub>B</sub> ≥ 0</font></p>

## 5. 最大显色比例

混合光谱：

<p align="center"><font face="Times New Roman">S<sub>mix</sub>(λ;ρ) = ρS<sub>W</sub>(λ) + w<sub>R</sub>S<sub>R</sub>(λ) + w<sub>G</sub>S<sub>G</sub>(λ) + w<sub>B</sub>S<sub>B</sub>(λ)</font></p>

显色函数：

<p align="center"><font face="Times New Roman">R<sub>a</sub>(ρ) = CRI[S<sub>mix</sub>(λ;ρ)]</font></p>

最优比例：

<p align="center"><font face="Times New Roman">ρ<sup>*</sup>(T) = arg max<sub>ρ∈Ω<sub>T</sub></sub> R<sub>a</sub>(ρ)</font></p>

定义：

<p align="center"><font face="Times New Roman">W<sub>0</sub>(T) = ρ<sup>*</sup>(T)</font></p>

## 6. 离散比例场

RGB 三角域网格：

<p align="center"><font face="Times New Roman">P<sub>ijk</sub> = [iP<sub>R</sub> + jP<sub>G</sub> + kP<sub>B</sub>] / N</font></p>

<p align="center"><font face="Times New Roman">i + j + k = N</font></p>

每个点保存：

<p align="center"><font face="Times New Roman">W<sub>0,ijk</sub> = W<sub>0</sub>(P<sub>ijk</sub>)</font></p>

该离散场表示基础温度条件下的最大显色白光比例分布。

## 7. 连续估计

对任意目标点 Z<sub>0</sub> = (u′<sub>0</sub>,v′<sub>0</sub>)，在其邻域内建立关于白光比例 W 的局部仿射近似：

<p align="center"><font face="Times New Roman">W(u′,v′) = a(u′ − u′<sub>0</sub>) + b(v′ − v′<sub>0</sub>) + c</font></p>

其中 a 与 b 表示比例场在 u′、v′ 两个方向上的局部一阶变化率，c 表示该局部模型在目标点 Z<sub>0</sub> 处的函数值。

通过欧式范数加权最小二乘求解：

<p align="center"><font face="Times New Roman">d<sub>n</sub> = ‖Z<sub>n</sub> − Z<sub>0</sub>‖<sub>2</sub> = [(u′<sub>n</sub> − u′<sub>0</sub>)<sup>2</sup> + (v′<sub>n</sub> − v′<sub>0</sub>)<sup>2</sup>]<sup>1/2</sup></font></p>

<p align="center"><font face="Times New Roman">ω<sub>n</sub> ∝ 1 / (d<sub>n</sub><sup>2</sup> + ε)</font></p>

<p align="center"><font face="Times New Roman">min Σω<sub>n</sub>[aΔu′<sub>n</sub> + bΔv′<sub>n</sub> + c − W<sub>n</sub>]<sup>2</sup></font></p>

求得参数 a、b、c 后，由于目标点处满足 u′ = u′<sub>0</sub> 且 v′ = v′<sub>0</sub>，因此：

<p align="center"><font face="Times New Roman">W(u′<sub>0</sub>,v′<sub>0</sub>) = a·0 + b·0 + c = c</font></p>

所以目标点处的基础比例估计为：

<p align="center"><font face="Times New Roman">W<sub>25</sub> = c</font></p>

## 8. **温度扰动修正**

温度归一化：

<p align="center"><font face="Times New Roman">t = [clamp(θ,θ<sub>0</sub>,θ<sub>max</sub>) − θ<sub>0</sub>] / [θ<sub>max</sub> − θ<sub>0</sub>]</font></p>

比例限幅：

<p align="center"><font face="Times New Roman">W = clamp(W<sub>25</sub>,0,1)</font></p>

分段曲面：

<p align="center"><font face="Times New Roman">ΔW = tF<sub>1,s</sub>(x,y,W) + t<sup>2</sup>F<sub>2,s</sub>(x,y,W)</font></p>

<p align="center"><font face="Times New Roman">W<sub>formula</sub> = clamp(W + ΔW,0,1)</font></p>

其中 F<sub>1,s</sub> 与 F<sub>2,s</sub> 是由十项基函数构成的分段多项式。

十项基函数及其意义如下：

| 序号 | 基函数 | 意义 |
|---:|---|---|
| 0 | φ<sub>0</sub> = 1 | 常数偏置项，描述整体平均温度偏移 |
| 1 | φ<sub>1</sub> = x | 目标色度 x 的一阶影响 |
| 2 | φ<sub>2</sub> = y | 目标色度 y 的一阶影响 |
| 3 | φ<sub>3</sub> = W | 基础白光比例的一阶影响 |
| 4 | φ<sub>4</sub> = xy | x 与 y 的色度耦合项 |
| 5 | φ<sub>5</sub> = xW | x 与基础比例的耦合项 |
| 6 | φ<sub>6</sub> = yW | y 与基础比例的耦合项 |
| 7 | φ<sub>7</sub> = W<sup>2</sup> | 基础比例的二阶非线性 |
| 8 | φ<sub>8</sub> = x<sup>2</sup> | x 方向二阶曲率 |
| 9 | φ<sub>9</sub> = y<sup>2</sup> | y 方向二阶曲率 |

## 9. 可行域约束

设 W<sub>max</sub> 为目标颜色在当前 RGB 凸包内允许的最大白光比例。

<p align="center"><font face="Times New Roman">W<sub>final</sub> = min(W<sub>formula</sub>,W<sub>max</sub>)</font></p>

最终四通道驱动向量：

<p align="center"><font face="Times New Roman">d<sub>RGBW</sub> = f<sub>mix</sub>(T,W<sub>final</sub>)</font></p>

## 10. 总模型

<p align="center"><font face="Times New Roman">W<sub>25</sub> = f<sub>local</sub>(u′,v′)</font></p>

<p align="center"><font face="Times New Roman">W<sub>formula</sub> = f<sub>thermal</sub>(x,y,W<sub>25</sub>,θ)</font></p>

<p align="center"><font face="Times New Roman">W<sub>final</sub> = min(W<sub>formula</sub>,W<sub>max</sub>)</font></p>

<p align="center"><font face="Times New Roman">d<sub>RGBW</sub> = f<sub>mix</sub>(T,W<sub>final</sub>)</font></p>

## 11. 闭环表达

该模型以最大显色比例 ρ<sup>*</sup> 为光谱最优目标，以 W<sub>25</sub> 表示基础比例场的连续估计，以 W<sub>formula</sub> 表示温度扰动修正，以 W<sub>final</sub> 表示满足几何可行域的最终比例。

<p align="center"><font face="Times New Roman">T → Ω<sub>T</sub> → ρ<sup>*</sup>(T) → W<sub>25</sub> → W<sub>formula</sub> → W<sub>final</sub> → d<sub>RGBW</sub></font></p>
